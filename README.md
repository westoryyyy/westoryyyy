I'm a builder who found her way into Web3, and never left.

Most blockchain products are built by people who love the tech. I love the **people using it**. So I design interfaces that make sense on the first try, then write the smart contracts to back them up. Design is where I'm at home. Solidity is how I make sure the product isn't just pretty, it's *trustworthy*.
